# 아침매거진 클론 프로젝트 - 디자인 시스템 가이드 (Design System)

본 가이드는 프리미엄 에디토리얼 브랜드 '아침(Achim)'의 감성을 웹으로 구현하기 위한 프론트엔드 스타일링 지침입니다. 모든 6인의 팀원은 담당 페이지라우터(`journal`, `mart`, `membership` 등)를 작업할 때 이 규칙을 엄수해야 합니다.

---

## 1. 코어 디자인 원칙 (Core Principles)
- **과감한 여백 (Breathing Space)**: 콘텐츠 사이사이에 넉넉한 공간을 두어 사용자가 서두르지 않고 둘러볼 수 있게 합니다.
- **문학적인 타이포그래피**: 화려한 UI보다는 타이포그래피의 자간, 행간 비율이 아름다움을 결정합니다.
- **2D / 직선 지향**: 모든 그림자(Drop-shadow, Box-shadow) 사용을 원천 금지합니다. 오직 미세한 보더 라인으로만 경계를 짓습니다.

---

## 2. 컬러 팔레트 (Color System)
웹사이트 전반의 색상은 극도로 절제해야 하며, 아래에 정의된 변수만 사용합니다.

```css
:root {
  --background: #faf8f5;    /* 웜 크림색 (차분하고 따뜻한 흰색) */
  --foreground: #1a1a1a;    /* 니어 블랙 (가독성은 높이면서 눈의 피로 최소화) */
  --primary: #e65c00;       /* 에디토리얼 오렌지 (과도하게 튀지 않는 포인트 컬러) */
  --secondary: #f5f2ee;     /* 미세한 명도 차이를 주기 위한 보조 배경색 */
  --muted: #737373;         /* 부가 설명, 날짜 등에 사용되는 연한 텍스트 */
  --border: #1a1a1a;        /* 구분선 및 아웃라인 버튼용 흑색 */
  --white: #ffffff;         /* 완전 흰색 (오버레이 및 버튼 호버 텍스트용) */
}
```

## 3. 타이포그래피 (Typography)

### 3.1 폰트 패밀리
- **일반 본문 및 제목 (Sans-serif)**: `Pretendard`, `Inter`, `sans-serif`
- **시그니처 브랜드 로고 및 영문 대형 타이틀 (Serif)**: `Cardo`, `serif`

### 3.2 텍스트 서식화
- **행간 (Line Height)**: 국문 가독성을 위해 기본 `1.9` 이상의 넉넉한 행간을 보장합니다.
- **자간 (Letter Spacing)**:
  - 본문: `-0.01em` (살짝 타이트하고 단단하게)
  - 제목 (Heading): `-0.04em` (응집력 확보)
  - 영문 라벨 및 네비게이션: `0.05em ~ 0.15em` (넓은 자간으로 고급스러운 느낌)
- **대문자 (Text Transform)**: 메뉴, 버튼(일부), 카테고리 태그(`FEATURED`, `JOURNAL`)는 반드시 `ALL CAPS` 형태를 지향합니다.

---

## 4. UI 컴포넌트 스타일링

### 4.1 여백 및 레이아웃 (Spacing)
- **섹션 간 여백**: `var(--spacing-section)` (180px)
- **이미지 비율**: 
  - 잡지 화보 느낌을 위해 기본적으로 **3:4 (또는 4:5)**의 수직 비율 사용.
  - 히어로 등 일부 가로형 섹션에서는 4:3 사용.

### 4.2 버튼 및 링크 (Buttons & Links)
- **일반 버튼 (CTA)**: 
  - 둥근 알약 형태 (Pill-shape): `border-radius: 50px`
  - 아웃라인: `border: 1px solid var(--border)`
  - 배경: 투명 (Hover 시 `var(--foreground)`로 채워지며 텍스트는 흰색)
- **에디토리얼 링크**: 
  - `Shop Now`와 같은 액션 링크는 굵은 버튼 대신 **밑줄 (Underline)** 사용.
  - `text-underline-offset: 6px`로 글씨와 밑줄 사이의 간격을 여유 있게 확보.

### 4.3 이미지 및 인터랙션 (Images & Interactions)
- **이미지 둥글기 (Border Radius)**: 각진 직선 형태(0px)를 원칙으로 합니다.
- **이미지 호버 효과**: 이미지 확대 애니메이션은 `1.05배` 스케일과 `1.2s` 정도의 부드러운 타이밍을 가지도록 설정합니다.
- **그림자 금지**: 어떠한 상황에서도(팝업 제외) 카드 뷰 레이아웃에 `box-shadow`를 사용하지 않습니다.

---

## 5. 담당 페이지 개발 지침
새로운 페이지라우터를 개발할 때에는 `src/app/globals.css`에 선언된 `var(--)` CSS 변수를 사용하여 색상과 여백 값을 할당하십시오. 하드코딩된 `#hex` 색상 사용은 삼가 주시길 바랍니다.
